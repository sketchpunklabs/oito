const nodeBuilder = new WebGPUNodeBuilder();
nodeBuilder.setMaterial( material );
shader = nodeBuilder.parse( shader.vertexShader, shader.fragmentShader );

parse checks material.color.isNode
then this.addSlot( 'fragment', new NodeSlot( material.color, 'COLOR', 'v3' ) );

Then moves onto 
fragmentShader = this.buildShader( 'fragment', fragmentShader );
which then calls this.build( shader ) // shader == 'fragment'
the build is not part of webGPU builder but inherited from nodebuilder

---
nodeBuilder.build( 'fragment' );
Grabs the slots for fragment
loops then calls this.flowData( slot.node );

flowNode then does
return { result: node.build( builderRef ) };
which is the main excutor for a node

---
node.build calls this.generate( builderRef )

OperatorNode
calls the .build for A & B objects & saves its results.
then returns with 
builder.format( '('+a+' '+this.op+' '+b+')', nodeType, output );
which tries to do automatic data conversion.

Vector3Node which is A & B
calls generate which just does
builder.generateVec3( this.value.x, this.value.y, this.value.z );
which returns return `vec3( ${x}, ${y}, ${z} )`;
